# GridSignals runtime dependencies.
#
# The project is stdlib-only by rule (urllib + xml.etree + sqlite3). The ONE
# sanctioned exception is the UI layer, which may use vetted third-party web
# packages to reach executive/CISO-grade polish. Everything outside the UI
# (ingest, resolve, classify, score, licensing, plays, supersede, audit, db)
# imports nothing from here. No component libraries (Plotly/echarts/aggrid/
# pydeck); R8.1 cards are custom HTML/CSS per R8.9.
#
# UI stack (app/ui_web/) — the FastAPI + HTMX + Tailwind port (R8.9). HTMX is
# vendored (app/ui_web/static/htmx.min.js) and Tailwind builds to committed CSS
# via the standalone CLI, so neither is a Python dependency. python-multipart
# lets FastAPI parse the feedback form POST; httpx backs Starlette's TestClient
# used by the hermetic UI tests.
